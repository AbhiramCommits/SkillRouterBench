# Evidence Lookup Skill

When to use: When an inquiry requires factual support, product data, or commercial metrics.

Procedure:
1. Extract key search entities (product name, region, topic) from the inquiry.
2. Formulate search queries for the MCP documents server.
3. If tabular metrics are requested, query the MCP tabular metrics server.
4. Retrieve top-k documents and verify relevance and citations.
